# 11 — Onde a skill difere do LicitarsAI original (e por quê)

Os arquivos de `assets/base/` e de `assets/components/` são **a versão da skill**:
corrigida e parametrizada. Os de `assets/exemplos/` são **cópias do LicitarsAI**,
só para leitura. Quando os dois divergem, **vale a skill** (base + referências).
